N100 上使用 OpenWrt/iStoreOS 标准服务脚本：

```
/etc/init.d/go2rtc-c700
```

直接执行裸服务启动时，默认会先切到小米 cloud-relay：

```
/etc/init.d/go2rtc-c700 start
```

等价于先执行：

```
/opt/go2rtc-c700/switch-mode.sh cloud
```

再启动服务。

你可以 SSH 到 N100 后这样运维：

```
/etc/init.d/go2rtc-c700 start
/etc/init.d/go2rtc-c700 stop
/etc/init.d/go2rtc-c700 restart
/etc/init.d/go2rtc-c700 status
/etc/init.d/go2rtc-c700 enable
/etc/init.d/go2rtc-c700 disable
```

为了接近 Mac 上的 `.command` 使用方式，N100 上可以再放两个包装脚本：

```
/opt/go2rtc-c700/go2rtc-c700.sh
/opt/go2rtc-c700/switch-mode.sh
```

常用命令：

```
/opt/go2rtc-c700/go2rtc-c700.sh start
/opt/go2rtc-c700/go2rtc-c700.sh stop
/opt/go2rtc-c700/go2rtc-c700.sh restart
/opt/go2rtc-c700/go2rtc-c700.sh status
/opt/go2rtc-c700/go2rtc-c700.sh logs

/opt/go2rtc-c700/go2rtc-c700.sh start cloud
/opt/go2rtc-c700/go2rtc-c700.sh start lan 3
/opt/go2rtc-c700/go2rtc-c700.sh mode cloud
/opt/go2rtc-c700/go2rtc-c700.sh mode lan 3
```

其中：

```
cloud = c700_remote_sim
lan   = c700_lan
```

`mode` 只改配置里的稳定流 `c700:`，不会自动重启；`start cloud|lan` 会先切模式再启动服务。已运行时切模式后执行：

```
/opt/go2rtc-c700/go2rtc-c700.sh restart
```

配置和程序在：

```
/opt/go2rtc-c700/go2rtc
/opt/go2rtc-c700/go2rtc.yaml
```

日志看：

```
logread -e go2rtc
```
